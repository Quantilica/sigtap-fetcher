## Origem e coleta

- O fetcher baixa, por FTP, o ZIP de cada competência do SIGTAP em `ftp2.datasus.gov.br`, pasta `/pub/sistemas/tup/downloads`. O nome na fonte é `TabelaUnificada_AAAAMM.zip` ou, quando o DATASUS regera a tabela, `TabelaUnificada_AAAAMM_vAAMMDDHHMM.zip`; o sufixo é a data e a hora da geração.
- No bruto, o arquivo fica em `tabelas/` com o carimbo de data da versão baixada (`TabelaUnificada_AAAAMM_vAAMMDDHHMM@AAAAMMDD.zip`).
- Este dataset vem do membro `rl_procedimento_habilitacao.txt` do ZIP (dados, uma linha por registro, largura fixa) e do layout `rl_procedimento_habilitacao_layout.txt`, que dá nome, tamanho e posição de cada coluna. O ZIP traz ainda o layout reunido de todas as tabelas (`layout.txt`), a planilha 'DATASUS - Tabela de Procedimentos - Lay-out.xls' (dicionário oficial) e o `LEIA_ME.TXT` (histórico das mudanças da estrutura). O fetcher guarda o ZIP inteiro; o conversor lê só os membros `tb_*.txt` e `rl_*.txt` e os layouts.
- Conferido em 2026-11-15 pelo tamanho dos membros dos 227 ZIPs publicados (2008-01 a 2026-11, uma competência por mês, sem lacunas), `rl_procedimento_habilitacao.txt` existe e tem conteúdo em todos.

## Conteúdo

- Unidade de análise: um vínculo entre um procedimento, uma habilitação e, quando houver, um grupo de habilitações.
- Linhas por competência: 4.364 em 2008-01, 11.635 em 2026-11; entre as 227 competências convertidas para esta página, de 4.353 a 11.635. Cada competência traz a tabela inteira, não só o que mudou.
- Em 2026-11 são 11.635 vínculos para 2.006 procedimentos; 10.363 deles (89%) têm `nu_grupo_habilitacao` nulo.

## Variáveis

As descrições seguem a planilha oficial de layout do ZIP ('DATASUS - Tabela de Procedimentos - Lay-out.xls'), conferidas contra os valores observados em 2026-11. Onde os dados diferem da planilha, isso está dito na coluna 'Unidade / códigos'.

## No lake

- Dataset `sigtap/rl_procedimento_habilitacao`, particionado por `ano` (inteiro) e `mes` (texto de 2 dígitos, `05`); um arquivo Parquet por ZIP de competência, em `ano=AAAA/mes=MM/`.
- O conversor lê cada linha de largura fixa com o layout do próprio ZIP, aparando espaços nas pontas; campo em branco vira nulo e texto é decodificado de ISO-8859-1 para UTF-8.
- Colunas numéricas viram inteiros ou decimais conforme o layout; valor que não converte vira nulo. Os valores `9999` que a fonte usa como 'não se aplica' ficam como estão.
- Linhas totalmente em branco são ignoradas. Se um ZIP traz mais de uma versão da mesma competência, só a de maior sufixo `_v` é convertida.
- As colunas `versao` (sufixo `_v` do ZIP) e `competencia` (AAAAMM, igual às pastas `ano=`/`mes=`) são acrescentadas pelo conversor.
- `dt_competencia` é a coluna do arquivo, mantida como texto.

## Cuidados de uso

- **Cada competência é uma fotografia completa, não um incremento.** Sem filtrar `competencia`, o mesmo registro aparece uma vez por competência (esta tabela soma 1.352.737 linhas nas 227 competências convertidas, contra 11.635 em 2026-11). Filtre uma competência ou compare competências explicitamente.
- A fonte descreve o grupo como o conjunto de habilitações exigidas em conjunto (LEIA_ME do ZIP); o que significa uma linha sem grupo não é explicado pela fonte.
- **Junte sempre pela mesma competência.** Códigos, nomes e valores mudam de uma competência para outra; unir tabelas de competências diferentes dá resultados que nunca existiram no SIGTAP.

## Exemplos

Procedimentos com exigência de grupo de habilitação na competência mais recente.

```python
import duckdb

duckdb.sql("""
    SELECT nu_grupo_habilitacao, count(DISTINCT co_procedimento) AS procedimentos
    FROM read_parquet('lake/sigtap/rl_procedimento_habilitacao/**/*.parquet', hive_partitioning = true, union_by_name = true)
    WHERE competencia = '202611' AND nu_grupo_habilitacao IS NOT NULL
    GROUP BY 1
    ORDER BY 2 DESC
    LIMIT 10
""").show()
```
